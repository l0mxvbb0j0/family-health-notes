# 剖腹产手术前禁食禁水的时间

> 更新时间：2026-09-15 (UTC+8)

剖腹产手术前禁食禁水的时间 更新时间:2017-12-21

对于生孩子的方式，很多妈妈选择手术，有的妈咪可能害怕顺产疼，所以选择剖腹产，有的妈咪可能就是各种原因不适合顺产只能剖腹产，还有一种是顺产一半，实在顺产不下来，最后还是选择剖腹产。有的准妈感觉剖腹产比较安全，生的时候不疼，其实这只是错觉，其实剖腹产一点也不轻松，产后恢复很慢，生完孩子肚子很疼。现在讲讲剖腹产手术产前产后的全过程。

一，剖腹产手术前

1.6小时以上禁食禁水

做剖腹产手术医生一般是提前预约，要求手术前6个小时不能吃东西还有喝水，要空腹做手术，怕手术时，胃里的东西逆流进气管引起，所以要做手术前的那一顿饭最好吃多一点，要不生了孩子以后也不能吃东西，只能是排气后才能吃，要饿好久。

2.备皮

“备皮”是什么?当时自己的第一反应是在身上取下一块皮为做剖腹产手术备用，感觉好恐怖。来到检查室，护士吩咐脱下裤子躺倒病床上，具体的“备皮”操作就是把下面的体毛刮干净，消毒为手术做准备，备皮”一小会就做完了。

3.插导尿管

手术前半个小时插导尿管，感觉这个有点疼，感觉不是很舒服，因为是躺着进行，也没看清楚具体的步骤，只是插的时候有点疼，一小会就好了。

二，剖腹产手术中

1.打麻药

终于来到手术室，和想象的差不多，里面灯光很亮，手术台上旁边有很多器械，医生给打上点滴，之后开始打麻药，医生要求准妈咪侧着身子，弯曲成“虾米状”麻醉师在脊柱上打进去麻药，扎的时候有点疼，打进去感觉不明显了，一小会就昏昏入睡了。

2. 剖腹产手术

剖腹产手术一般有两种情况一种是没有意思的情况下做剖腹产手术，因为是打了麻药的原因，准妈可能会睡着，在没有知觉的情况下做手术，我当时就是这样，睡了一觉，做了一个梦，孩子就生出来了。还有一种情况是准妈妈对麻药不敏感，清醒的情况下做手术，就是剖腹产手术中的所有情况都知道，我的一个同学就是这样子，剖腹产手术中的所有情况他都知道，感觉这样好恐怖，还是睡一觉比较好，醒着太可怕。

3.缝合伤口

剖腹产手术结束，孩子生出来，下一步就是缝合伤口，把手术的伤口缝合起来。我当时缝合伤口的时候，麻药的劲过了，疼醒了，感觉是有人在拉扯我的肚子，很痛，咬着牙挺过去的。

三，剖腹产手术后

1.消毒+压沙袋+压肚子

剖腹产后要每隔2小时护士要对下面进行消毒，肚子上压着沙袋，是为了伤口尽快恢复，每次护士来消毒的时候，都会使劲的压我的肚子，每次疼的我都一身汗，一压下面就会出来很多的血。

2.排气：

一般是手术后6小时内必须排气，所谓的排气就是“放屁”，排气后才能吃东西，排气的好处就是为了防止，排气后就能吃饭了。

3. 侧卧

术后6个小时取下压在肚子上得沙袋，护士要求侧身躺，使身体和床倾斜成20 ～30角，护士说这个姿势可以减轻对切口的震动和牵拉痛，有助于伤口愈合，但是肚子很疼，这个动作不好操作，肚子实在太疼了，根本都不了

4.

我是对麻药不是很敏感，在缝针的时候就疼醒了，手术完了，肚子还是很疼，虽说用了止疼泵，感觉一点作用没有，特别是护士压肚子的时候，真的无法形容这个疼痛，感觉五脏六腑都要被挤出来的感觉。

5. 腰疼

手术过后的几天，肚子还是有点疼，但是比刚生完孩子的时候好很多，就是腰直不起来，走路一只手掐着腰，一只手托着肚子，能走一点路了，但还是不能走远。

6，拆线

手术后的第5-6天，就可以出院了，这个时候剖腹产手术伤口也可以拆线了，拆线真很简单，护士拿着剪刀一剪就好了，很快，也不疼。

今天我又把剖腹产生孩子的过程又回忆一遍，如果老天在给一次机会的话，我一定选择顺产生孩子，在甜甜妈看来，准妈们还是能生还是自己生孩子，顺产只是生的时候疼，生完了就没事了，可以立马下床，剖腹产生孩子的话，产后要恢复好久，关键是生了孩子还要疼好久，恢复起来也很慢，能自己生的准妈，建议顺产，对大人孩子都好，产后痛苦小。
